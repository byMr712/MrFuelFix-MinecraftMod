## Что делает этот мод? (Простыми словами)

Знакома ситуация: в печи уже жарится железо или еда, вы зажимаете **Shift** и кликаете по **доскам, брёвнам или палкам**, чтобы закинуть их в качестве топлива... но **ничего не происходит**? Предмет просто не хочет перемещаться в печь, и его приходится перетаскивать мышкой вручную!

### В чём причина для игрока?
В ванильной игре дерево, палки и брёвна могут **и гореть, и переплавляться** (например, брёвна переплавляются в древесный уголь). Из-за недоработки в коде игра сначала пытается положить их в верхний слот плавки. Если верхний слот уже занят (там жарится руда), игра «сдаётся» и даже не пытается отправить дерево в нижний слот для топлива!

### Как это решает мод:
- **Умное перемещение:** Нажмите **Shift + ЛКМ** на любое топливо (доски, брёвна, палки, стержни ифрита и т.д.) — если верхний слот занят или полон, оно **автоматически отправится в нижний слот топлива**!
- Больше никаких ручных перетаскиваний топлива мышкой.
- Работает во всех видах печей: **Обычная печь**, **Плавильня** и **Коптильня**.

## Совместимость

- Работает со всеми видами печей: **Обычная печь (Furnace)**, **Плавильня (Blast Furnace)**, **Коптильня (Smoker)**.
- Полная совместимость с любыми модами на кастомные рецепты (включая **[[MR] Recipe Editor](https://www.curseforge.com/minecraft/mc-mods/mr-recipe-editor)**), где обычному топливу могут быть добавлены рецепты плавки.
- Работает как в одиночной игре, так и на серверах (Client & Server).
- Полная локализация интерфейса (`ru_ru`, `en_us`).

## Для разработчиков: Техническое объяснение бага

### Проблема в ванильном коде

В оригинальном Minecraft логика метода `AbstractFurnaceScreenHandler.quickMove` устроена следующим образом:
```java
if (this.isSmeltable(itemStack)) {
    if (!this.insertItem(itemStack, 0, 1, false)) {
        return ItemStack.EMPTY; // Блокировка!
    }
} else if (this.isFuel(itemStack)) {
    if (!this.insertItem(itemStack, 1, 2, false)) {
        return ItemStack.EMPTY;
    }
}
```

Если предмет является **одновременно и топливом, и переплавляемым ресурсом** (брёвна, древесина, доски, палки, стержни ифрита, уголь при наличии кастомных рецептов):
1. Игра видит, что предмет переплавляемый (`isSmeltable`), и пытается положить его в верхний слот 0.
2. Если в верхнем слоте **уже лежит другой предмет** (или стак полон), `insertItem` возвращает `false`.
3. Игра немедленно завершает операцию (`return ItemStack.EMPTY`).
4. До ветки `else if (this.isFuel)` очередь **никогда не доходит**!
5. Топливо намертво застревает в инвентаре игрока и не кладётся в слот топлива по Shift-клику.

### Как работает патч мода
- Если предмет переплавляемый — он пытается зайти в верхний слот (слот 0).
- Если предмет также является топливом, и верхний слот занят другим предметом или не смог принять весь стак — остаток (или весь стак) перенаправляется в нижний слот топлива (слот 1).
- Если оба слота печи заняты — предмет корректно перемещается между инвентарём и хотбаром по стандартным правилам.
